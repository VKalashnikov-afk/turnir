# Турнир по настольному теннису: Android-приложение

Это проект приложения: окно со встроенным браузером, внутри которого открывается файл
`app/src/main/assets/index.html` (ваш турнир). Интернет не нужен, разрешения не требуются.

Готовый установочный файл (APK) собирает бесплатно GitHub, ничего устанавливать на компьютер не нужно.

## Как получить APK

1. Зайдите на github.com и войдите в аккаунт (или зарегистрируйтесь).
2. Нажмите «+» вверху справа, затем «New repository». Назовите, например, `turnir`, нажмите «Create repository».
3. На странице нового репозитория нажмите «uploading an existing file».
4. Распакуйте этот архив и перетащите в окно браузера ВСЁ содержимое папки:
   `app`, `.github`, `build.gradle`, `settings.gradle`, `gradle.properties`, `.gitignore`.
   Нажмите «Commit changes».
5. Проверьте, что в репозитории есть папка `.github/workflows` с файлом `build-apk.yml`.
   Если папки нет (бывает, что браузер не перетаскивает папки с точки в названии), нажмите
   «Add file» → «Create new file», в поле имени введите `.github/workflows/build-apk.yml`,
   вставьте туда текст из файла `build-apk.yml` из архива и нажмите «Commit changes».
6. Откройте вкладку «Actions». Если сборка не началась сама, выберите слева «Build APK»
   и нажмите «Run workflow».
7. Через 3–6 минут напротив сборки появится зелёная галочка. Откройте её, внизу в разделе
   «Artifacts» скачайте `Turnir-APK`. Это zip, внутри файл `Turnir.apk`.
8. Отправьте `Turnir.apk` другу.

## Как установить на Android

1. Открыть файл `Turnir.apk` на телефоне.
2. Когда Android попросит, разрешить установку из этого источника (мессенджер или «Файлы»).
3. Если Google Play Protect покажет предупреждение, нажать «Всё равно установить» (приложение не из магазина).
4. Открыть приложение «Турнир» по значку.

## Важно

* Если соберёте новую версию APK, перед её установкой удалите старую. Подпись при каждой сборке новая,
  поэтому Android не даёт поставить новую версию поверх. Результаты турнира при удалении пропадают,
  поэтому заранее скопируйте код во вкладке «Ещё» → «Скопировать код».
* Чтобы обновить сам турнир, замените файл `app/src/main/assets/index.html` в репозитории
  на новый `turnir.html` (с тем же именем `index.html`) и дождитесь новой сборки.
